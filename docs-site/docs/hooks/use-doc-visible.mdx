# useDocVisible

Tracks whether the browser tab/document is currently visible to the user,
backed by the Page Visibility API and `useSyncExternalStore` for tear-free
concurrent rendering.

## When to use it

- Pausing video/audio playback when the user switches tabs.
- Pausing or throttling API polling while the tab is hidden.
- Building analytics that measure real engagement time vs. background time.

## Signature

```ts
function useDocVisible(options?: UseDocVisibleOptions): boolean;

interface UseDocVisibleOptions {
  onChange?: (isVisible: boolean) => void;
}
```

| Parameter | Type                   | Description                                             |
| --------- | ---------------------- | ------------------------------------------------------- |
| `options` | `UseDocVisibleOptions` | Optional `onChange` callback fired on visibility flips. |

**Returns:** `boolean` — `true` while the document is visible.

## Usage notes

- Built on `useSyncExternalStore`, so it's safe under React's concurrent
  rendering without tearing.
- Defaults to `true` during server-side rendering to avoid hydration
  mismatches.
- The `onChange` callback only fires when the visibility actually changes,
  never on every render.
