# useLatest

Returns a stable ref that always holds the latest value, so long-lived
closures can read fresh props, state or callbacks without stale captures.

## When to use it

- Calling the latest callback from a timer, event listener or async handler
  without re-subscribing.
- Keeping effects with stable dependencies while still reading current values.

## Signature

```ts
function useLatest<T>(value: T): RefObject<T>;
```

**Returns:** a ref whose `current` is the latest `value`. It is synchronized
after each commit, so read it inside callbacks or effects, not during render.

## Example

```tsx
const onTickRef = useLatest(onTick);

useEffect(() => {
  const id = setInterval(() => onTickRef.current(), 1000);
  return () => clearInterval(id);
}, [onTickRef]);
```
