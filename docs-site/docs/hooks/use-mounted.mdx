# useMounted

Tracks whether a component is currently mounted, and optionally runs
`onMount`/`onUnmount` lifecycle callbacks — including an `onMount` cleanup
function, just like `useEffect`.

## When to use it

- Guarding against "set state on an unmounted component" warnings after an
  async operation resolves late.
- Running setup/teardown logic tied to a component's lifecycle in a single
  place.
- Encapsulating lifecycle logging or side effects reusable across components.

## Signature

```ts
function useMounted(options?: UseMountedOptions): () => boolean;

interface UseMountedOptions {
  onMount?: () => void | (() => void);
  onUnmount?: () => void;
}
```

| Parameter | Type                | Description                                         |
| --------- | ------------------- | --------------------------------------------------- |
| `options` | `UseMountedOptions` | Optional `onMount`/`onUnmount` lifecycle callbacks. |

**Returns:** `() => boolean` — call it to check if the component is still
mounted.

## Usage notes

- `onMount` may return a cleanup function (same convention as `useEffect`),
  which runs automatically right before `onUnmount`.
- The returned `isMounted()` function has a stable identity, so it's safe to
  reference inside async callbacks without adding it as a dependency.
