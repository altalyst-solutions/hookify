# useOutsideClick

Invokes a callback whenever a click or touch event occurs outside a given
element. Ideal for closing dropdowns, modals, or popovers automatically.

## When to use it

- Closing a dropdown menu when the user clicks elsewhere on the page.
- Dismissing a modal or tooltip on an outside click/tap.
- Any UI that should collapse when focus moves away from it.

## Signature

```ts
function useOutsideClick(
  ref: RefObject<HTMLElement>,
  callback: () => void
): void;
```

| Parameter  | Type                     | Description                                            |
| ---------- | ------------------------ | ------------------------------------------------------ |
| `ref`      | `RefObject<HTMLElement>` | Ref of the element to detect outside clicks against.   |
| `callback` | `() => void`             | Invoked when a click/touch occurs outside the element. |

**Returns:** `void`

## Usage notes

- Listens for both `click` and `touchstart` events, so it works well on
  touch devices too.
- Automatically removes its event listeners on unmount.
- The callback fires only when the event target is outside the referenced
  element (clicks inside it are ignored).
